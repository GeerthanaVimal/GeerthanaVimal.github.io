GEERTHANA VIMALAMBIKAI PAKAN - 3D BOOK PORTFOLIO
================================================

This is a 3D book-style personal portfolio website. Open index.html to
run the complete portfolio.

MAIN FILE
---------
index.html -> Main book, page structure, and navigation controller.

SEPARATE PAGES
--------------
home.html     -> Home page
about.html    -> About page
research.html -> Research and Publications
projects.html -> Projects
skills.html   -> Technical Skills
contact.html  -> Contact information

OTHER FILES
-----------
stylesheet.css  -> Website design, layout, colors, animations, and
                   responsive styling.
main-original.js -> Page flipping, Previous/Next controls, keyboard,
                    touch/swipe navigation, and page counter.

HOW TO EDIT
-----------
To change content, edit only the required HTML file.

Home       -> home.html
About      -> about.html
Research   -> research.html
Projects   -> projects.html
Skills     -> skills.html
Contact    -> contact.html

To change the overall design, edit stylesheet.css.
To change navigation or page flipping, edit main-original.js.
To change the main book structure, edit index.html.

NAVIGATION
----------
The Previous and Next controls are located at the bottom of the book.
The pages can also be changed using the top navigation menu, keyboard
Left/Right arrow keys, or touch/swipe gestures.

IMPORTANT
---------
Keep all HTML, CSS, and JavaScript files in the same main folder.
Do not rename files unless their references are also updated in
index.html.


FUTURE UPDATES
--------------
The website is designed for easy maintenance. Edit only the page you
need to update, then open index.html to test the complete portfolio.

Always keep a backup before making major changes.
