ASSETS
======
img/    Put profile and project images here.
cv/     Put your CV here as Geerthana_CV.pdf.
css/    Local icon styling (icons.css).
icons/  Reserved for future local SVG/icon files.

The social icons currently use Font Awesome from a CDN, so no icon-font
files are required in this folder. Boxicons is also loaded from its CDN
for the portfolio UI icons.
