RFID-Based Smart Door Lock System Using Arduino

May 2022 – Sep 2022

This project is a secure, convenient access control system built with an Arduino UNO. Users carry RFID cards or tags with unique ID data. When a card is held near the MFRC522 reader, the Arduino compares its ID against the authorized one. If it matches, a servo motor unlocks the door, and an I2C LCD displays “Authorized Access” with a countdown before the door automatically relocks. Unrecognized cards trigger an “Access denied” message. The system restricts entry to approved individuals, provides clear user feedback, and suits homes, offices, and other places where controlled access matters.

Arduino-Based Fire Fighting Robot

Sep 2021 – Apr 2022

This project is an autonomous robot that detects and extinguishes fires using an Arduino microcontroller. Three flame sensors, placed left, right, and forward, continuously scan for fire. When a flame is detected, the Arduino drives the DC motors to steer the robot toward it. Once in range, the robot stops and activates a water pump, while a servo motor sweeps the nozzle back and forth to spray the flames effectively. The robot then returns to monitoring mode. By combining sensing, motor control, and automated suppression, it offers a fast, efficient solution for fire safety and disaster management.

ATM System Using C++

This project is a C++ program that simulates a basic ATM through a menu-driven console interface. Built with an object-oriented class structure, it stores account details such as name, account number, account type, and balance, and supports key banking operations: entering account information, checking balance, depositing money, and withdrawing funds. The program runs in a continuous loop until the user chooses to exit, keeping interaction simple and clear. It demonstrates core programming concepts including classes, encapsulation, switch statements, and user input handling, serving as a solid foundation for understanding how real banking systems manage transactions.

Digital Thermometer using LM35 and PIC Microcontroller

This project designs a digital thermometer that measures temperature and shows it on a 7-segment display. An LM35 temperature sensor is connected to a PIC microcontroller (such as the PIC16F877A), which reads the sensor’s output and converts it into a temperature value. The reading is then displayed in digital form on a common cathode or common anode 7-segment display. The circuit also uses resistors, capacitors, and a power supply. A program written for the PIC microcontroller handles the sensing and display logic, and the whole design was simulated in Proteus to verify that it works correctly.

Comprehensive Analysis on Cardiovascular Disease

This project aims to predict the presence of cardiovascular disease using patient health and lifestyle data. The problem addressed is that assessing cardiovascular risk involves analysing several factors, including age, blood pressure, body mass index (BMI), cholesterol, glucose, smoking, alcohol use, and physical activity. To explore an automated solution, the project analyses the cardiovascular dataset, cleans and preprocesses the data, handles outliers, creates BMI, encodes categorical features, and scales numerical values. It then trains a voting ensemble combining K-Nearest Neighbours, Logistic Regression, Support Vector Machine, and Random Forest classifiers. The model achieved 73% accuracy on the test dataset automatically.

BillMate – Restaurant Billing System

BillMate is a console-based restaurant billing system developed in C programming. It helps restaurant staff manage orders quickly and accurately. Cashiers log in with a secure PIN, select dishes from an editable menu, and choose dine-in or takeaway. The system automatically calculates promo discounts, service charges, GST and round-off, then generates a neat receipt with cash change calculation. All bills are stored in readable text files, so past invoices can be searched easily. Managers can view daily sales reports showing total earnings, payment methods and top-selling dishes. The project demonstrates file handling, structures, input validation and clean modular programming.
