# 📖 Geerthana Vimalambikaipakan — 3D Book Portfolio

Welcome to my personal **3D Book-Style Portfolio Website**.

This portfolio presents my academic background, AI/ML research, publications, projects, technical skills, and contact information through an interactive digital book interface.

The website is designed with a realistic **3D page-flipping experience**, responsive layout, and multiple navigation methods.

---

## 🌐 Portfolio Overview

The portfolio includes the following sections:

- 🏠 Home
- 👩‍💻 About Me
- 🔬 Research & Publications
- 🚀 Projects
- 🛠️ Technical Skills
- 📩 Contact

Users can navigate through the portfolio using page controls, keyboard navigation, touch gestures, or the top navigation menu.

---

## ✨ Features

- 📖 Interactive 3D book-style interface
- 🔄 Realistic page-flipping animation
- 🧭 Previous / Next navigation
- ⌨️ Keyboard navigation using Left / Right arrow keys
- 📱 Touch and swipe navigation
- 🔢 Page counter
- 📑 Separate HTML pages for easy content management
- 🎨 Responsive and modern design
- 💻 Works as a standalone front-end website
- 🔧 Easy to customize and maintain
